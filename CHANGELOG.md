- Changed `EntityID` to `E.Entity` throughout the codebase  
- Removed explicit `Component` instances (no longer required in aztecs 0.13)
- Updated type signatures for `updateHierarchy`, `hierarchy`, and `hierarchies` functions

- Basic working implementations of core functions compatible with aztecs 0.13
- Improved test suite with concrete functionality tests
